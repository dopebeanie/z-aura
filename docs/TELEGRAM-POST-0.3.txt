💜 | Z-Aura 0.3.0 — комфорт в деталях:

Новый тестовый билд: привычный zapret, удобнее интерфейс и меньше лишних действий.

Changelog
• RU / ENG — язык сохраняется, первый запуск на русском.
• Трей и мини-оверлей — возвращение окна, компактные статусы, перетаскивание и привязка к краям экрана.
• Быстрый старт можно пропустить, а инструкция всегда под рукой.
• Discord теперь внизу меню, над Telegram-каналом: после входа — круглый аватар, имя и @username.
• Красивая локальная страница Discord с кнопкой «Вернуться в приложение» — возвращает уже запущенное окно Z-Aura, без второй копии программы.
• Поправили края кнопок меню, подпись под таблицей журнала и размеры вкладок «Общие» / «Внешний вид».
• YouTube Focus — обратимая экспериментальная копия профиля. Исходные 22 стратегии Flowseal 1.10.4 сохранены.
• Telegram Proxy по-прежнему независим от zapret: конфиг, перезапуск, порт, uptime и журнал прямо в интерфейсе.
• Discord Presence показывает Alt + Zapret On/Off + Proxy On/Off, сохраняет таймер сеанса и автоматически переподключается. Вход в профиль необязателен.
• Всё в одном portable EXE — .NET, Python и зависимости отдельно устанавливать не нужно.

🧪 Живой OAuth, видео у вашего провайдера, чистая Windows и работа драйвера/службы ещё требуют проверки. Для входа Discord владельцу приложения нужно настроить Redirect URI; пользователям Developer Portal не нужен. Proxy: On подтверждает локальный порт, не гарантирует связь с Telegram.

Z-Aura — не VPN: не скрывает IP, не добавляет VPN-шифрование и не гарантирует анонимность.
