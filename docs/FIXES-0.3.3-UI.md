## Где включить новые поля и звук

«Панель управления» → «Опции» → «Звуки интерфейса»: включите звук, выберите
громкость и нажмите «Прослушать». Проверьте системную громкость Windows.
Ниже, в карточке Discord RPC, отдельно включаются скорость и достижения.
Предпросмотр показывает фактически сформированную активность. Скорость обновляется
примерно раз в 10 секунд; достижения появляются только после выполнения условий.
Прежние настройки приватности не включаются принудительно.
