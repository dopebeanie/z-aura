Z-Aura

Documents for the Windows application · revision {{effectiveDate}}

Z-Aura is a local interface for managing zapret/Flowseal profiles and resources, starting its own engine, configuring a Windows service and checking selected network destinations.

The app is not a VPN, does not add encryption and does not guarantee anonymity or website availability. Use it only where permitted by applicable law and your network rules.

Discord Rich Presence. While Z-Aura runs, it sends the selected profile and its own engine state to the running Discord desktop client. Discord may display this information to others according to its activity visibility settings.

Discord features

Rich Presence is independent of optional Discord sign-in. Sign-in uses the Discord browser page, S256 PKCE and the identify permission; a local page returns you to the existing window. The session is stored on your device using Windows DPAPI for the current user. Z-Aura has no server-side token storage, slash commands, interactions handler or linked-role verification.

Publishing these documents does not mean Discord has verified the app. Configuration and approval in Developer Portal are separate.
