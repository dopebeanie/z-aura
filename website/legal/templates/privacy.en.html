1. Scope and purposes

This policy describes the Windows app Z-Aura, its local Discord Rich Presence integration and this site. Data supports saving configuration, selected features, diagnostics and support requests. There is no separate Z-Aura account, cloud sync, advertising analytics or automatic crash-report upload in the current implementation.

2. Data on your device

  • Interface settings, active/recent profiles, filters, launch arguments and Presence settings.
  • Created/imported profiles, domain/IP lists, fake files, their paths and checksums.
  • Local logs with timestamps, engine messages and errors; messages may contain paths, addresses and configuration details.
  • Embedded-resource and .NET caches; an installed service has separate persistent configuration, resources and logs.

Files normally reside in %APPDATA%\Z-Aura. With portable.flag beside the EXE, user state and cache reside in adjacent data. The service uses %ProgramData%\Z-Aura\Service. Switching storage mode does not automatically move or delete old data.

3. Network traffic and diagnostics

When the engine runs, third-party zapret/WinDivert components process local network packets according to selected rules. This does not mean traffic content is sent to Z-Aura's developer. The app does not add encryption or make connections anonymous.

User-triggered diagnostics make HTTPS requests to tested domains and DNS requests through the current network. Destinations, DNS providers and intermediaries may receive normal connection information, including your IP and requested address. Their own policies apply.

Since Z-Aura 0.3.1, automatic version checks are enabled by default on application entry and every six hours; they can be disabled. Checks contact the GitHub API for dopebeanie/Z-Aura. Optional downloads contact GitHub Releases and release-assets.githubusercontent.com. GitHub receives normal connection data, including IP and the app version in User-Agent. Settings, logs, Discord profile and session statistics are not included. Automatic download is separately opt-in; installation requires restart confirmation. Cached EXEs/backups remain local. This updates Z-Aura, not the separate Flowseal runtime.

4. Discord Rich Presence and optional sign-in

Activity remains enabled while the Z-Aura GUI runs. There is no separate Presence toggle. Minimizing to tray does not quit Z-Aura or stop Presence.

When the Discord desktop client is available, Z-Aura sends it through local IPC:

  • Application ID and process ID for RPC.
  • The selected profile label, such as Alt: ALT10; a custom profile name may be used when no separate label is configured.
  • GUI-owned engine state and session start time.
  • Image keys, their descriptions and an optional “My Alt” button URL.

Discord processes this information and may show it to others according to its settings. Do not put personal or secret information in profile names or button URLs. Z-Aura never asks for your password, Bot Token or Client Secret. Voluntary browser OAuth2 with S256 PKCE requests only identify: public ID, name and avatar.

Since 0.3.2, the access token, refresh token (if issued by Discord), expiry and profile are stored in discord-session.bin, protected with Windows DPAPI CurrentUser, not plaintext settings.json. Sign-in survives app/PC restart; expired credentials are refreshed through Discord. Temporary network failure retains the session; a revoked grant requires new sign-in. Protection is tied to the Windows user/device and does not protect against malware already running with that user's permissions. Another PC/Windows account requires new sign-in. Avatars are fetched from Discord CDN without a bearer token or disk cache. The 127.0.0.1 return page contains no OAuth code, token or account details and restores the existing window. Account data is not sent to Presence.

Presence displays Alt, zapret/Proxy states and application uptime. Optional counters report successful GUI engine/Proxy starts and HTTPS checks in the current session, not traffic volume or speed. Telegram Proxy contacts Telegram and selected relays; its secret remains in local settings and is not sent to Presence.

Discord privacy/activity settings control visibility, which is not the same as stopping local IPC transmission. Quit Z-Aura or Discord to stop transmission. On normal shutdown, Z-Aura attempts to clear Presence and close IPC; immediate disappearance of published activity depends on Discord.

See Discord's privacy policy. Z-Aura's policy does not determine Discord retention periods.

5. Developer, support and external links

The app does not automatically upload local profiles, logs or traffic to the developer. If you voluntarily send a request, screenshot or log, its recipient uses the supplied information for support. Remove secrets and unnecessary personal information first. Public issues/messages may be visible to others; use private contact for sensitive information.

External destinations receive connection information when you visit them. The “My Alt” button may link to a user-selected third-party address whose policy applies separately.

The Donate card shows optional support details; copying occurs only on click. Transfers are made in your banking app. Z-Aura does not accept payments or collect payer bank details, CVV, PIN or verification codes. All features remain free. The bank processes transfers under its own rules.

6. This site and hosting

Documents are available in Russian and English. The only script stores your theme choice in this site's localStorage, otherwise applying the system theme. It contains no analytics, network requests, submission forms, advertising or cookies. The local return page switches language/theme without JavaScript or localStorage. The main information site also saves its theme and loads a Google Fonts font. This describes the code, not a claim that hosting infrastructure processes no data.

7. Retention and deletion

“Sign out of Discord profile” deletes the local saved session before attempting online grant revocation. If revocation fails, use Discord → Authorized Apps. Normal app exit retains sign-in; you can also delete discord-session.bin while Z-Aura is closed. Moving a portable folder to another PC does not transfer this authorization. Clear browser localStorage to remove the site theme.

Local configuration, resources and logs remain until you delete them; no automatic daily-log deletion period is set. Stop the GUI/engine before deleting the relevant folder or files and back up important profiles. Removing a service does not automatically delete all its resources; stop/remove it first and inspect its separate folder. Old data from another storage mode may need separate deletion.

For information voluntarily supplied to the responsible party, you may request access, correction or deletion using the contact below. Availability and timing depend on applicable law and required retention. Data held by Discord, hosting or another provider requires a request to that provider. Remote deletion of local device files or another party's data is not promised.

8. Changes and contact

This policy must be reviewed before new account, OAuth2, server, analytics or other processing features are introduced. For data questions, contact the responsible party below.
