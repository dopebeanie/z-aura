How it works

Three steps to start

Z-Aura does not rewrite the packet engine. It compiles arguments and directly starts bundled winws.

01

Download one EXE

The engine, WinDivert driver, lists, presets and fonts are bundled. No installed .NET, WebView2 or NSSM is needed.

02

Choose a profile

At startup, WPF verifies/restores resources using SHA-256 and checks the driver signature. Windows security is not automatically disabled.

03

Click Start

Z-Aura compiles arguments and starts the engine. Install a service directly from the interface for background operation.

Privacy

Your settings stay on your device

No Z-Aura accounts or automatic profile/log uploads to the developer. Presence and voluntary OAuth contact Discord; Proxy contacts Telegram and selected relays. Version checks contact GitHub, including normal connection data and IP, and can be disabled. External links open on click.

No mandatory account

All features work without sign-in. Discord OAuth requests only identify. The session is saved using Windows DPAPI for the current user; signing out deletes it. Account details are not sent to Presence.

Local data

Profiles, lists, logs and cache reside in %APPDATA%\Z-Aura or beside the EXE in data when using portable.flag.

Verifiable build

Resources are checked against SHA-256 at each startup, and the driver signature is verified before launch.

One file. Everything bundled.

Portable Z-Aura bundles the zapret 1.10.4 engine, driver, lists and fonts. Copy the EXE to a folder and run it — no installer.
