Как это работает

Три шага до запуска

Z-Aura не переписывает пакетный движок — он формирует аргументы и напрямую запускает встроенный winws.

01

Скачайте один EXE

Движок, драйвер WinDivert, списки, пресеты и шрифты уже встроены. Установленный .NET, WebView2 и NSSM не нужны.

02

Выберите профиль

При старте WPF восстанавливает ресурсы по SHA-256 и проверяет подпись драйвера. Windows-защита автоматически не отключается.

03

Нажмите «Запустить»

Z-Aura сам соберёт аргументы и запустит движок. Для фоновой работы можно установить службу — прямо из интерфейса.

Приватность

Ваши настройки — на вашем устройстве

Без аккаунтов Z-Aura и автоматической отправки профилей/журналов разработчику. Presence и добровольный OAuth обращаются к Discord; прокси — к Telegram и выбранным relay. Проверка обновлений обращается к GitHub (включая обычные данные соединения и IP); её можно отключить. Внешние ссылки открываются по нажатию.

Без обязательного аккаунта

Все возможности доступны без входа. Discord OAuth запрашивает только identify. Сеанс сохраняется с защитой Windows DPAPI для текущего пользователя; выход удаляет его. Данные аккаунта не передаются в Presence.

Локальные данные

Профили, списки, журналы и кэш лежат в %APPDATA%\Z-Aura или рядом с EXE в папке data при наличии portable.flag.

Проверяемая сборка

Целостность ресурсов сверяется по SHA-256 при каждом запуске, подпись драйвера проверяется перед стартом.
